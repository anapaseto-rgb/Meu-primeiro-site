# Meu-primeiro-site
Nesse blog vai com ter ideias de looks para você montar com as roupas do seu garda-roupas e roupas para você ter ideias comprar.
Sempre buscando a Santidade e modestia, mais sempre sendo estilosos

## O que eu aprendi

- Criar uma página HTML
- Usar a tag h1 para títulos
- Usar a tag p para parágrafos
- Organizar arquivos no VS Code

## Tecnologia utilizada

- HTML5
- Visual Studio Code

## Como abrir

Para visualizar o projeto, abra o arquivo index.html em um
